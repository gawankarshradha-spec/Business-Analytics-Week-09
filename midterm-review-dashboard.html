Question 2: Input, Conditions & Loops 25 points

Task 1 (option A) · Greatest of four numbers with a for loop

largest.py
num1 = int(input("Enter the first number: "))
num2 = int(input("Enter the second number: "))
num3 = int(input("Enter the third number: "))
num4 = int(input("Enter the fourth number: "))

# Initialize the greatest number with the first number
largest = num1

# Compare each remaining number with the current greatest number
for number in (num2, num3, num4):
    if number > largest:
        largest = number

print("Largest number =", largest)
Largest number = 78

Logic

  1. Start with a candidate. largest = num1; you must have something to compare against.
  2. for visits each of the other three numbers in turn, one per iteration.
  3. if number > largest: only a strictly bigger value replaces the candidate. Ties keep the earlier one.
  4. After the loop ends, largest holds the maximum. Three comparisons, no matter the order of inputs.

Task 1 (option B) · Driving eligibility with the not operator

eligibility.py
# Enter the person's age
age = int(input("Enter age: "))

# Check whether the age is outside the eligible range
if not (age > 15 and age < 18):
    print("Not eligible to drive in the simulation.")
else:
    print("Eligible to drive in the simulation.")
Not eligible to drive in the simulation.

Logic

  1. Eligible range is 15 < age < 18, so only ages 16 and 17 qualify.
  2. and is True only when both comparisons are True.
  3. not flips it: not True → False, not False → True. So the if branch runs for anyone outside the range.
  4. Python evaluates inside the parentheses first, then applies not, then chooses the branch.

Task 1 (option B) · Store squares of numbers in a dictionary

squares.py
def Sq_of_numbers(n):            # Define a function that accepts a number n
    d = dict()                   # Create an empty dictionary

    for i in range(1, n + 1):      # Loop through the numbers from 1 to n
        if i not in d:              # Check whether i is absent from the dictionary
            d[i] = i * i             # Store i as the key and its square as the value

    return d                     # Return the completed dictionary


print("Squares of numbers:")     # Display a heading
Z = Sq_of_numbers(5)             # Call the function with 5 and store the result in Z
print(Z)                         # Display the dictionary
Squares of numbers:
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

Logic

  1. range(1, n+1) produces 1…n. The +1 is needed because range stops before its end.
  2. d[i] = i * i adds a key:value pair. Keys are the numbers, values their squares.
  3. if i not in d guards against duplicate keys (always True here, but shows membership testing).
  4. return d hands the finished dict back to the caller, who stores it in Z.

Question 4: Reading Files & Exploring Data 25 points

Step 1 · Read Gym.csv with the with statement

read_gym.py
import csv  # Import the csv module

with open("Gym.csv", "r", encoding="utf-8") as file:  # Open the file
    reader = csv.reader(file)   # Create a CSV reader
    headings = next(reader)     # Read the headings
    responses = list(reader)    # Store the attendee responses

print(headings)                 # Display the headings
for row in responses:           # Loop through each response
    print(row)                  # Display the response

Logic

  1. with open(...) as file opens the file and closes it automatically when the block ends.
  2. csv.reader splits each line on commas into a list of strings.
  3. next(reader) consumes the first line (the headings) so it is not counted as data.
  4. list(reader) reads the remaining rows into responses, a list of lists. Each row is [Attendee, Age Group, Outcome], so the outcome is row[2].

Step 2 · Count Enroll vs Not Enroll (while loop OR for loop)

count_while.py
# Initialize counters
enroll = 0
not_enroll = 0
i = 0

# Check each attendee's outcome in the data already read
while i < len(responses):
    if responses[i][2] == "Enroll":
        enroll = enroll + 1
    elif responses[i][2] == "Not Enroll":
        not_enroll = not_enroll + 1

    i = i + 1  # Move to the next attendee

# Display the counts
print("Enroll:", enroll)
print("Not Enroll:", not_enroll)
count_for.py
# Initialize counters
enroll = 0
not_enroll = 0

# Check each attendee's outcome in the data already read
for row in responses:
    if row[2] == "Enroll":
        enroll = enroll + 1
    elif row[2] == "Not Enroll":
        not_enroll = not_enroll + 1

# Display the counts
print("Enroll:", enroll)
print("Not Enroll:", not_enroll)
Enroll: 140
Not Enroll: 260

Logic

  1. Counters start at 0. Two separate variables, one per category.
  2. while version needs its own index i, a condition i < len(responses), and i = i + 1 at the bottom. Forget the increment and the loop never ends.
  3. for version lets Python hand you each row directly. No index, no increment, same result.
  4. if / elif tests row[2] (the Outcome column) and adds 1 to the matching counter. Comparison is exact, so "Enroll" and "enroll" would not match.
Both programs produce identical counts. The exam accepts either; the for loop is shorter and safer, the while loop shows you control the index yourself.
